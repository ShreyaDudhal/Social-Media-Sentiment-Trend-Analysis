# Data Directory

This directory contains datasets for the Social Media Sentiment and Trend Analysis project.

## Files:
- `sample_social_media.csv`: Synthetic demonstration dataset containing 350 realistic social media records with user mentions, engagement metrics, hashtags, and sentiment distributions.

## Expected Columns:
- `user_id`: Username/User Identifier (e.g. U001, U002)
- `post`: Post/Tweet text content
- `timestamp`: Creation timestamp (YYYY-MM-DD HH:MM:SS)
- `likes`: Integer count of likes
- `comments`: Integer count of comments
- `shares`: Integer count of shares/retweets
- `hashtags`: Hashtag string (e.g. `#AI #Python`)
- `mentioned_user`: Username mentioned in the post (e.g. `U005`)
